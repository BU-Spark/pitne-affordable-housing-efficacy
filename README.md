## Data locations

In this section, you should include the location of all of your datasets for the project (if applicable)

<a href="dataset-documentation">Dataset Documentation</a>

### **Location 1: CHAPA Secure Drive (Raw Data)**
**Location:** BU Spark! × CHAPA Google Drive (restricted access)  
- Contains **raw housing lottery application data** received directly from CHAPA.  
- Includes applicant demographics, income, assets, and property information from **October 2023 – May 2025**.  
- Access limited to authorized BU Spark! teams under the data-use agreement.  
- This serves as the **primary source of truth** for all downstream processing.

---

### **Location 2: Local Processed Data**
**Path:** `fa25-team-b/data/`  
- Holds **cleaned and transformed** datasets generated by scripts in `cleaners/` and `scripts/`.  
- Intermediate files used for EDA and visual analysis.  
- Not committed to GitHub due to privacy; regenerated programmatically from the CHAPA raw data.  
- Example outputs:  
  - `clean_applications.parquet`  
  - `demographics_by_property.csv`

---

### **Location 3: Dataset Documentation**
**Path:** `dataset-documentation/`  
- Contains **data dictionaries, column mappings, and schema references** for all datasets.  
- Documents the variable meanings, normalization rules, and preprocessing logic used across teams (A & B).  
- Example:  
  - `chapter40b_data_dictionary.md`  
  - `variable_normalization_guide.md`

---

### **Location 4: Supporting Data Assets**
**Path:** `fa25-team-b/assets/`  
- Reference datasets used to enrich or cross-validate CHAPA data.  
- Example files:  
  - `city_names_norm_ma.csv` — standardized list of Massachusetts cities used for geographic encoding.  
- Used by scripts in `cleaners/geographic_encoding_ma_cities.py` and `tools/schema.py`.

---

### **Location 5: Configuration Files**
**Path:** `fa25-team-b/config/`  
- Contains YAML configuration files that define data-column mappings and dataset parameters.  
- Ensures consistent variable naming and schema across all pipelines.  
- Example files:  
  - `columns.yaml` — field renaming and normalization schema.  
  - `datasets.yaml` — dataset-level configuration used in automation scripts.

---

### **Location 6: Visualized Outputs**
**Path:** `fa25-team-b/visuals/`  
- Contains **final visualizations** derived from the processed datasets.  
- Examples:  
  - `applications_map.html` — interactive map of affordable-housing applications.  
  - `applications_pareto.png`, `top_properties_stacked.png` — property-level analysis visuals.  
  - Subfolders:  
    - `Age Restricted Analysis/` — plots for age-restricted property patterns.  
    - `Income and Demographics vs Applications/` — income and diversity-related visual summaries.  

---

### **Location 7: Research & Documentation**
**Path:** `fa25-team-b/docs/`  
- Houses written research files and project definition documents.  
- Example:  
  - `project_definition.md` — scope and objectives.  
  - `research.md` — contextual literature and CHAPA background.
